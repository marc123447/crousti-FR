Crousti FR, landing page de recrutement adulte

Fichiers:
- index.html : structure de la page
- styles.css : identité visuelle et responsive
- script.js : contrôle 18+, menu mobile et message de confirmation du formulaire

Mise en ligne:
1. Ouvrir index.html pour prévisualiser le site.
2. Héberger les trois fichiers sur un hébergeur statique.
3. Remplacer le traitement de formulaire dans script.js par un endpoint sécurisé ou un outil de formulaire.
4. Ajouter les vraies pages Mentions légales et Confidentialité avant publication.

Note: le formulaire est volontairement en mode démonstration. Il ne transmet aucune donnée tant qu’un backend ou un service de formulaires n’est pas connecté.
